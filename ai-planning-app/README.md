# 🤖 AI Planning Assistant - Telegram Mini App

AI yordamida kuningizni rejalashtirish, vaqtni samarali boshqarish va maqsadlaringizga erishish uchun Telegram Mini App.

## ✨ Xususiyatlar

### 📝 Vazifa Boshqaruvi
- Kunlik vazifalar ro'yxati
- Vazifalarni belgilash va o'chirish
- Bajarilgan vazifalarni kuzatish
- Vazifalarni filtrlash (barchasi/kutilmoqda/bajarilgan)

### 🎯 Maqsadlar Boshqaruvi
- Uzoq va qisqa muddatli maqsadlar
- Ustuvorlik darajalari (past/o'rta/yuqori)
- Maqsadlar progressini kuzatish

### ⏰ Pomodoro Timer
- 25 daqiqalik ish sessiyalari
- 5 daqiqalik qisqa dam olish
- 15 daqiqalik uzoq dam olish
- Sessiyalar statistikasi

### 🤖 AI Yordamchisi
- Aqlli tavsiyalar
- Samaradorlik bo'yicha maslahatlar
- Vaqt boshqaruvi strategiyalari
- Motivatsiya va maqsad belgilash

### 📊 Dashboard
- Bugungi vazifalar soni
- Bajarilgan vazifalar
- Fokus vaqti
- Faol maqsadlar

## 🚀 O'rnatish va Ishga Tushirish

### 1. Loyihani Yuklab Olish
```bash
git clone <repository-url>
cd ai-planning-app
```

### 2. Lokal Server Ishga Tushirish
```bash
# Python 3 bilan
python -m http.server 8000

# Yoki Node.js bilan
npm start
```

### 3. Telegram Bot Yaratish

1. [@BotFather](https://t.me/botfather) ga o'ting
2. `/newbot` buyrug'ini yuboring
3. Bot nomini va username ni kiriting
4. Bot tokenini oling

### 4. Mini App Sozlash

1. BotFather da `/newapp` buyrug'ini yuboring
2. Botingizni tanlang
3. App nomini kiriting: "AI Planning Assistant"
4. App tavsifini kiriting
5. App URL ni kiriting: `https://yourdomain.com` (HTTPS kerak)
6. App ikonkasini yuklang

### 5. Web App URL Sozlash

BotFather da:
```
/setmenubutton
@your_bot_username
Web App
https://yourdomain.com
```

## 🛠 Texnologiyalar

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Telegram API**: Telegram Web Apps SDK
- **Storage**: LocalStorage (ma'lumotlar saqlash)
- **AI Integration**: Simulated AI responses (keyinchalik real AI API qo'shiladi)
